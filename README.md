Data analysis and visualization using Python, Pandas, NumPy, and Matplotlib.

Machine learning project for predicting house prices using Python and Scikit-learn.

### Project 4 - Disease Prediction

Machine learning classification project involving data preprocessing, handling class imbalance, and model training.
